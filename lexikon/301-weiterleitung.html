301-Weiterleitung

Die dauerhafte Umleitung einer alten Adresse auf eine neue - der Rettungsanker bei jedem Umbau.

Kontor

SEO-Agentur

Kapitel
    Kostenlose SEO-Analyse

    Eine 301-Weiterleitung sagt Browser und Suchmaschine: Diese Adresse gibt es nicht mehr, der Inhalt liegt dauerhaft dort. Im Unterschied zur 302, die nur eine vorübergehende Umleitung meldet, gibt die 301 den größten Teil der aufgebauten Signale an das neue Ziel weiter.

    Wann man sie braucht

    Bei jedem Umbau, der Adressen verändert: neues System, neue Struktur, Umzug auf eine andere Domain, Wechsel auf HTTPS. Ohne Weiterleitung verliert jede Seite, die rankte, ihre Position, und Besucher landen auf einer Fehlerseite.

    So geht man vor

    Vor dem Umbau eine vollständige Liste aller bestehenden Adressen ziehen. Nach dem Umbau für jede eine Weiterleitung auf die inhaltlich passende neue Seite setzen - nicht pauschal alles auf die Startseite. Eine pauschale Umleitung aller alten Adressen auf die Startseite wertet Google wie eine Fehlerseite.
